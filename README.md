# Приложение: вёрстка и бэкенд

Node.js + Express + SQLite (встроенный `node:sqlite`). Единственная зависимость — `express`.

## Запуск

```bash
npm install
cp .env.example .env   # задайте ADMIN_PASSWORD
npm start
```

- Приложение: http://127.0.0.1:3000
- Админ-панель: http://127.0.0.1:3000/pages/admin.html
- Проверка с телефона в одной сети: `HOST=0.0.0.0` в `.env`, затем открыть `http://<IP компьютера>:3000`

`npm test` запускает автотесты API.

## Как это работает

- **Админ** входит по единому паролю из `.env` и создаёт пользователей. Для каждого выдаётся одноразовый код вида `XXXXX-XXXXX`.
- **Пользователь** вводит код один раз. Код сгорает, а устройство остаётся авторизованным (cookie на год). Если cookie потеряна (очистили браузер, новый телефон), админ выдаёт новый код кнопкой «Новый код».
- **Отзыв доступа** выкидывает пользователя из приложения сразу на всех устройствах.
- **Фото документа** загружается тапом по чёрному квадрату на странице «Удостоверение личности» и **только один раз**: перед загрузкой приложение предупреждает, после неё рамка закрывается. Чтобы разрешить замену, админ нажимает «Новый код»: пользователь выходит из приложения и после входа по новому коду может один раз загрузить другое фото (старое файл удаляется). Фото хранится в `data/uploads/` и отдаётся только владельцу. Данные и фото лежат в `data/` — копируйте её для бэкапа.

## Структура

```
server/   бэкенд (app.js, routes/, db.js, security.js)
pages/    HTML-страницы (закрыты входом, кроме login.html и admin.html)
css/ js/ assets/   публичная статика
test/     автотесты API
```
